# Krate Creative Space website

The new krate.com.my: an independent theatre company and creative community in Melaka.

## Pages
- `index.html`: home
- `tears-under-the-rising-sun.html`: Tears Under the Rising Sun, 14 and 15 November 2026
- `a-chefs-confession.html`: A Chef’s Confession
- `book.html`: private shows, event space, workshops and murals, with WhatsApp enquiries

## Hosting on GitHub Pages
1. Settings → Pages → Build and deployment: deploy from the `main` branch, root folder.
2. To use krate.com.my, add it under Settings → Pages → Custom domain first, then update the domain’s DNS.
3. Once the domain connects, tick “Enforce HTTPS”.

The show pages switch from “Our next show” to “Past show” automatically after 10pm on 15 November 2026 (Malaysia time).
